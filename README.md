# なら優しいイベントナビ v6.0

## 🌟 概要

**なら優しいイベントナビ v6.0** は、奈良市のバリアフリー情報を統合した、誰もが安心して楽しめる情報プラットフォームです。

### 主な特徴

✅ **473施設のバリアフリー情報** - 公共施設409件、駅11件、観光施設53件  
✅ **2つの表示モード** - イベント情報 & 施設バリアフリー情報  
✅ **詳細なフィルタリング** - カテゴリー、徒歩時間、バリアフリー設備  
✅ **地図表示** - インタラクティブな地図で位置確認  
✅ **統計ダッシュボード** - バリアフリー設備の普及率を可視化  
✅ **経路案内** - 自宅から目的地までの詳細ルート

## 🚀 使い方

### 1. セットアップ

1. ZIPファイルを解凍
2. `index.html` をブラウザで開く
3. インターネット接続が必要 (地図表示のため)

### 2. イベントモード

```
📅 イベント情報タブ
1. カテゴリー、徒歩時間、バリアフリー設備でフィルタ
2. イベントカードをクリックして詳細確認
3. 「経路を表示」で最寄り駅からのルート確認
```

### 3. 施設モード (新機能)

```
♿ バリアフリー施設情報タブ
1. 施設タイプ (公共施設/駅/観光施設) で絞り込み
2. バリアフリー設備で絞り込み
3. 施設名で検索
4. 地図上で位置確認
5. 統計パネルで全体傾向を把握
```

### 4. 自宅住所登録

```
🏠 自宅住所を登録
1. 「自宅住所を登録」ボタンをクリック
2. 住所を入力 (例: 奈良市左京2丁目)
3. 最寄り駅が自動的に検索される
4. 各イベント/施設への経路案内が利用可能に
```
