# ならやさしいイベントナビ v4.0

奈良市のバリアフリー対応イベント情報と経路案内を提供するWebアプリケーションです。

## 🆕 v4.0 新機能

### 徒歩ルート最適化
- **歩行者専用ルートを使用**: OpenStreetMap Routing Service (OSRM) の `foot` プロファイルを採用
- **車道を避けた経路**: 歩道、遊歩道、公園の小道など、歩行者が実際に通れる道を優先
- **より正確な距離と時間**: 実際の歩行ルートに基づいた距離・時間を表示
- **地図上の視覚化改善**: 徒歩ルートを緑の実線で明確に表示

### 経路表示のシンプル化
- **駅マーカーの強調**: 出発駅と到着駅を大きな丸いアイコンで表示
- **徒歩ルートのみ表示**: 電車の線路は表示せず、徒歩経路に焦点
- **明快なルート案内**: 自宅→出発駅→到着駅→会場の4点を明確に表示

## ✨ 主要機能

### 1. イベント情報の表示とフィルタリング
- **18件のバリアフリー対応イベント**を掲載
- カテゴリー別フィルター（文化、スポーツ、教育など）
- バリアフリー設備でのフィルター（車椅子、エレベーター、多目的トイレ）
- 駅からの徒歩時間フィルター（5/10/15/20分）

### 2. インタラクティブ地図
- **Leaflet.js** と **OpenStreetMap** を使用
- イベント会場、鉄道駅、自宅を地図上に表示
- バリアフリー対応度で色分けされたマーカー
  - 🟢 緑: 車椅子対応完備
  - 🟡 黄: 一部対応
  - 🔴 赤: 情報なし

### 3. 経路案内機能
- **自宅住所登録**: ブラウザに保存され、次回も利用可能
- **最寄り駅自動検出**: 自宅とイベント会場の最寄り駅を自動計算
- **徒歩ルート提案**: OSRM API による実際の歩行ルートを表示
- **駅のバリアフリー情報**: 各駅の設備情報を詳細表示
- **所要時間計算**: 徒歩時間を正確に算出

### 4. イベント情報送信機能
- **4つの送信方法**: 郵送、電話、LINE、メール
- イベント詳細とバリアフリー情報を自動フォーマット
- 自宅住所と連絡先も含めて送信可能

### 5. アクセシビリティ対応
- **文字サイズ調整**: 拡大/縮小ボタン
- **ハイコントラストモード**: 視認性向上
- **キーボードナビゲーション**: Tab/Enterキーで操作可能
- **スクリーンリーダー対応**: ARIA属性による支援

## 🛠️ 技術仕様

### フロントエンド
- **HTML5**, **CSS3**, **JavaScript (ES6+)**
- **Leaflet.js 1.9.4**: 地図表示ライブラリ
- **OpenStreetMap**: 地図タイル
- **localStorage**: ユーザー設定の保存

### API
- **Nominatim API**: 住所のジオコーディング
- **OSRM API (foot profile)**: 徒歩ルート計算
  - エンドポイント: `https://router.project-osrm.org/route/v1/foot/`
  - プロファイル: `foot` (歩行者専用)
  - 特徴: 歩道、遊歩道、階段、公園の小道を優先

### アルゴリズム
- **距離計算**: Haversine公式
- **最寄り駅検索**: 全駅との距離を計算し最短を選択
- **徒歩時間推定**: 時速4kmで計算

### イベントデータ
- **18件**のバリアフリー対応イベント
- 奈良市広報誌（2024年11月号）から抽出

## 🌐 GitHub Pagesでの公開

### 基本手順

1. **GitHubリポジトリを作成**
   - Public リポジトリとして作成
   - リポジトリ名は任意（例: `nara-event-navi`）

2. **ファイルをアップロード**
   - ZIPを解凍後、以下のファイルとフォルダをアップロード:
     - `index.html`
     - `css/` フォルダ（`style.css` を含む）
     - `js/` フォルダ（`data.js` と `main.js` を含む）
     - `README.md`

3. **GitHub Pagesを有効化**
   - Settings → Pages
   - Source: "Deploy from a branch"
   - Branch: `main`、Folder: `/ (root)`
   - Save をクリック

4. **公開URLを確認**
   - 数分後、以下のURLでアクセス可能:
   ```
   https://あなたのユーザー名.github.io/リポジトリ名/
   ```

### ⚠️ 重要な注意点

#### パスの設定
このバージョンでは、GitHub Pagesでの公開を考慮して**相対パス**を使用しています：

```html
<!-- CSS -->
<link rel="stylesheet" href="./css/style.css">

<!-- JavaScript -->
<script src="./js/data.js"></script>
<script src="./js/main.js"></script>
```

`./` で始まる相対パスにより、ローカルとGitHub Pages両方で正しく動作します。

#### ファイル構造の確認
GitHubリポジトリのルートに以下の構造が必要です：

```
リポジトリルート/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── data.js
│   └── main.js
└── README.md
```

**❌ 間違った構造（動作しません）:**
```
リポジトリルート/
└── nara_event_navi_v4/
    ├── index.html
    ├── css/
    └── js/
```

## 🔧 トラブルシューティング

### GitHub Pagesで表示されない場合

#### 1. CSSや地図が表示されない
**原因**: ファイルパスが正しくない
**対処法**:
- ブラウザの開発者ツール（F12）でコンソールを確認
- 404エラーが出ている場合、ファイル構造を確認
- `index.html` がリポジトリのルートにあるか確認

#### 2. ページが404エラーになる
**原因**: GitHub Pagesが有効化されていない
**対処法**:
- Settings → Pages で設定を確認
- Branch が `main` で Folder が `/ (root)` になっているか確認

#### 3. デプロイが失敗する
**原因**: リポジトリがPrivateになっている
**対処法**:
- 無料プランではPublicリポジトリが必要
- Settings → General → Change visibility → Public

### 地図が表示されない
- インターネット接続を確認
- ブラウザのコンソールでエラーを確認
- Leaflet.jsのCDNリンクを確認

### 徒歩ルートが表示されない
- OSRM APIの利用制限に達している可能性があります
- 時間を置いて再試行してください
- エラー詳細はブラウザのコンソールで確認できます

### 自宅住所が登録できない
- 住所に「奈良市」を含めてください
- より詳細な住所を入力してください（番地まで）

### 駅が見つからない
- 徒歩時間フィルターを調整してください（20分まで拡大）
- 自宅住所が正確かどうか確認してください

## 📜 制限事項

### API制限
- **OSRM API**: 1秒あたり5リクエストまで
- **Nominatim API**: 1秒あたり1リクエストまで

### 徒歩ルートの精度
- 実際の道路状況（工事、閉鎖など）は反映されません
- 天候や時間帯による変動は考慮されません
- 坂道や階段の情報は限定的です

### データの更新
- イベント情報は手動更新が必要
- 駅のバリアフリー情報は定期確認が推奨されます
