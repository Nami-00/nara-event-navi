# ならやさしいイベントナビ v6 - 利用者管理対応版

## 📋 概要
奈良市のイベント情報を検索・表示するWebサイトに、**複数の利用者を管理する機能**を追加しました。各利用者ごとに個別の設定を保存し、利用者を切り替えることで、その人に合ったイベント情報を表示できます。

## ✨ 新機能

### 1. 利用者設定ボタン（ヘッダー最上部）
- サイトの一番上に「👥 利用者設定」ボタンを配置
- ワンクリックで利用者管理画面を開けます

### 2. 現在の利用者表示バー
- ヘッダー下部に現在選択中の利用者名を表示
- 「利用者を切り替え」ボタンで簡単に切り替え可能

### 3. 利用者管理機能

#### 利用者の登録
- 利用者名（必須）
- 自宅住所
- 最寄り駅（住所から自動検索）
- 通知方法（メール、LINE、FAX、郵送）
- 各通知方法の連絡先詳細
- イベント絞り込み条件
  - カテゴリー
  - 必要なバリアフリー設備
  - 最寄り駅からの徒歩時間

#### 利用者の管理
- 登録済み利用者の一覧表示
- 利用者カードに設定内容を表示
- 利用者の選択・切り替え
- 利用者情報の編集
- 利用者の削除

### 4. 利用者ごとの個別設定

各利用者について、以下の情報を個別に保存します：

#### 自宅住所
- 詳細な住所を登録
- 住所から最寄り駅を自動検索（候補3つから選択）
- 経路案内で使用

#### 通知先設定
- **メール**: メールアドレスを登録
- **LINE**: LINE IDを登録
- **FAX**: FAX番号を登録
- **郵送**: 郵送先住所を登録
- 複数の通知方法を同時に設定可能

#### イベント絞り込み条件
- **カテゴリー**: 文化・イベント、美術・展示、音楽・芸術など
- **バリアフリー設備**: 多目的トイレ、エレベータ、車椅子貸出など
- **徒歩時間**: 5分以内、10分以内、15分以内など

### 5. 利用者切り替え機能
- 利用者を選択すると、その人の設定が自動的に適用
- イベント一覧が選択した利用者の絞り込み条件でフィルタリング
- 自宅住所と最寄り駅が切り替わり、経路案内に反映

## 🎯 使い方

### 初回利用時
1. ヘッダーの「👥 利用者設定」ボタンをクリック
2. 「新しい利用者を追加」ボタンをクリック
3. 利用者情報を入力
   - 利用者名を入力（必須）
   - 自宅住所を入力（任意）
   - 「住所から最寄り駅を検索」ボタンで最寄り駅を自動検索
   - 通知方法を選択し、連絡先を入力
   - イベント絞り込み条件を設定
4. 「保存」ボタンで登録完了

### 利用者の切り替え
1. ヘッダー下の「利用者を切り替え」ボタンをクリック
2. 切り替えたい利用者のカードで「この利用者を選択」ボタンをクリック
3. 画面が自動的に更新され、選択した利用者の設定が適用されます

### 利用者情報の編集
1. 利用者管理画面で「編集」ボタンをクリック
2. 情報を修正
3. 「保存」ボタンで更新完了

### 利用者の削除
1. 利用者管理画面で「削除」ボタンをクリック
2. 確認ダイアログで「OK」をクリック

## 💾 データ保存
- すべての利用者データはブラウザのローカルストレージに保存
- サーバーへの送信は行わないため、プライバシーが保護されます
- ブラウザのデータを削除すると、利用者データも削除されます

## 📱 利用シーン

### 家族での利用
- お父さん用、お母さん用、おじいちゃん用など、家族それぞれの設定を登録
- 各自の好みや必要な設備に合わせたイベント情報を表示

### 福祉施設での利用
- 複数の利用者の情報を一元管理
- 各利用者に合わせたイベント提案が可能
- 通知先を個別に設定して、適切な方法で情報を配信

### ケアマネージャーの業務支援
- 担当する複数の高齢者の情報を管理
- それぞれの身体状況に合わせたイベントを素早く検索

## 🛠️ 技術仕様

### ファイル構成
```
nara-event-navi-enhanced/
├── index.html                    # メインHTMLファイル（利用者設定UI追加）
├── css/
│   └── style.css                 # スタイルシート（利用者管理用スタイル追加）
└── js/
    ├── data.js                   # イベントデータと駅データ
    ├── main.js                   # メイン機能（元のまま）
    └── user-management.js        # 利用者管理機能（新規）
```

### 新規ファイル
- **user-management.js**: 利用者管理のすべての機能を実装
  - 利用者の追加・編集・削除
  - 利用者の選択と切り替え
  - LocalStorageへのデータ保存・読み込み
  - 利用者設定の適用

### 既存ファイルへの変更
- **index.html**: 
  - 利用者設定ボタンをヘッダーに追加
  - 現在の利用者表示バーを追加
  - 利用者管理モーダルを追加
  - 利用者編集モーダルを追加
  
- **style.css**: 
  - 利用者管理UI用のスタイルを追加
  - 利用者カード、ボタン、フォーム要素のスタイル

- **main.js**: 変更なし（そのまま動作）

## 🔧 動作環境
- モダンブラウザ（Chrome、Firefox、Edge、Safari）
- JavaScript有効
- LocalStorage使用可能

## 📝 注意事項
1. ブラウザのLocalStorageを使用しているため、同じブラウザ・同じデバイスでのみデータを共有できます
2. ブラウザのキャッシュやCookieを削除すると、利用者データも削除されます
3. 定期的にバックアップを取ることをお勧めします（将来的にエクスポート機能を追加予定）
