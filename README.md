# ならやさしいイベントナビ v3.0

奈良市内のイベント情報と公共施設・鉄道駅のバリアフリー情報を統合したWebサイトです。
ハンディキャップをお持ちの方が安心してイベントに参加できるよう、詳細な経路案内とバリアフリー情報を提供します。

## 🆕 バージョン3.0の新機能

### 1. シンプルで分かりやすい経路表示
- ✅ **徒歩ルートのみ表示**: 道路に沿った実際の徒歩経路のみを表示
- ✅ **駅は丸マーカーで表示**: 最寄り駅を大きな丸で強調表示
- ✅ **鉄道の線を削除**: 複雑な路線表示をなくし、見やすさを向上

### 2. イベント情報の送信機能
- ✅ **📮 郵送**: イベント情報を郵送で受け取る
- ✅ **📞 電話**: 電話での案内を受ける
- ✅ **💬 LINE**: LINE経由で情報を受け取る
- ✅ **📧 メール**: メールで情報を受け取る

### 3. 連絡先管理機能
- ✅ 連絡先を一度登録すれば、すべてのイベントで利用可能
- ✅ 名前、電話番号、メール、LINE ID、郵送先を登録
- ✅ localStorage に安全に保存

### 4. サイト名変更
- 🎉 「やさしい奈良」→「**ならやさしいイベントナビ**」

## 🚀 使い方

### 1. 自宅住所の登録
1. 「🏠 自宅住所設定」ボタンをクリック
2. 住所を入力（例: 奈良市登大路町30）
3. 保存

### 2. 連絡先の登録（NEW）
1. 「📮 連絡先設定」ボタンをクリック
2. 必要な連絡先を入力:
   - お名前
   - 📞 電話番号
   - 📧 メールアドレス
   - 💬 LINE ID
   - 📮 郵便番号・住所
3. 保存

### 3. イベントを探す
1. カテゴリーまたはバリアフリー設備でフィルタリング
2. 「駅から徒歩」で時間を絞り込み
3. イベントカードをクリックして詳細を表示

### 4. 経路を確認
1. イベント詳細で「🚃 自宅から経路を調べる」をクリック
2. 以下が表示されます:
   - 🚶 自宅→最寄り駅の徒歩ルート（緑の点線）
   - 🚉 最寄り駅（大きな青い丸）
   - 🚃 電車での移動時間
   - 🚉 会場最寄り駅（大きなオレンジの丸）
   - 🚶 駅→会場の徒歩ルート（緑の点線）
   - ♿ 各駅のバリアフリー情報

### 5. イベント情報を送信（NEW）
1. イベント詳細で「📤 イベント情報を送る」セクションを確認
2. 希望の送信方法を選択:
   - 📮 郵送で受け取る
   - 📞 電話で案内を受ける
   - 💬 LINEで受け取る
   - 📧 メールで受け取る
3. 送信内容を確認
4. 「送信する」をクリック

## 🗺️ 経路表示の改善（v3.0）

### Before（v2.0）
- 鉄道ルートを青い線で表示
- 複雑で見づらい
- 実際の路線と合わない場合がある

### After（v3.0）
- ✅ **徒歩ルートのみ表示**（緑の点線）
- ✅ **駅は大きな丸マーカー**で表示
  - 🔵 青い丸: 自宅最寄り駅
  - 🟠 オレンジの丸: 会場最寄り駅
- ✅ **シンプルで分かりやすい**

```
🏠 自宅
  ↓ (緑の点線・徒歩ルート)
🟦 自宅最寄り駅（大きな青い丸）
  ↓ (電車で移動)
🟧 会場最寄り駅（大きなオレンジの丸）
  ↓ (緑の点線・徒歩ルート)
📍 イベント会場
```

## 🔐 プライバシーとセキュリティ

### データの保存場所
- すべてのデータは**ブラウザのlocalStorage**に保存
- サーバーには送信されません
- 個人情報は端末内で管理

### データの削除
- ブラウザのキャッシュをクリアすると削除されます
- 設定から個別に削除することも可能（今後実装予定）

### 情報送信について
- 現在はデモ版のため、実際の送信は行われません
- 実運用時はサーバー側の実装が必要です

## 🐛 既知の制限事項

1. **情報送信機能**
   - 現在はデモ版（実際の送信は行われない）
   - 実運用にはサーバー側実装が必要
