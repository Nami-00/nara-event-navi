## 🎉 v5の新機能

v3をベースに以下の6つの新機能を実装しました:

### ① 徒歩ルート最適化
- **OSRM footプロファイル**を採用
- 車道ではなく歩行者専用の最適ルートを提案
- より安全で快適な経路案内

### ② 経路表示のシンプル化
- **駅マーカーを強調表示**（大きく見やすい🚉アイコン）
- 徒歩ルートのみを表示
- 地図が見やすく、わかりやすく改善

### ③ 最寄り駅の候補選択
- 自宅住所登録時に**最寄り駅候補を3つ表示**
- 各駅までの距離とバリアフリー情報を表示
- よく利用する駅を選択して登録可能

### ④ 絞り込み条件の自動配信
- カテゴリーとバリアフリー設備で絞り込み条件を設定
- **「絞り込み条件を保存して自動配信を設定」ボタン**を追加
- 条件に合致するイベント情報が自動配信される（準備中）

### ⑤ 盲導犬・介助犬・聴導犬同伴可の情報追加
- バリアフリー設備に**「盲導犬・介助犬・聴導犬同伴可」**を追加
- アイコン: 🐕‍🦺
- 28件すべてのイベントに同伴可否情報を記載

### ⑥ 経路情報の共有機能
- 徒歩ルートの地図を含めた画面を配信
- **共有方法:**
  - メールで共有
  - LINEで共有
  - 画像として保存（準備中）
  - リンクをコピー

## 🚀 GitHub Pagesへのデプロイ方法

### 前提条件
- GitHubアカウント
- 既存のリポジトリ（または新規作成）

### 手順1: v5ブランチを作成

```bash
# リポジトリに移動
cd your-repository

# v5ブランチを作成して切り替え
git checkout -b v5

# すべてのファイルをコピー
# (nara_v5フォルダ内の全ファイルをリポジトリのルートにコピー)

# 変更をコミット
git add .
git commit -m "Add v5 with 6 new features"

# GitHubにプッシュ
git push origin v5
```

### 手順2: GitHub Pagesの設定

1. GitHubリポジトリページを開く
2. **Settings** → **Pages** をクリック
3. **Source** セクションで:
   - Branch: `v5`
   - Folder: `/ (root)`
4. **Save** をクリック
5. 2〜5分待つ
6. `https://[ユーザー名].github.io/[リポジトリ名]/` にアクセス

### Web UIでのアップロード方法

1. **v5ブランチを作成**
2. **ファイルを順番にアップロード:**

   **a. CSS:**
   - 「Add file」→「Create new file」
   - ファイル名: `css/style.css`
   - 内容をコピー＆ペースト
   - コミット

   **b. JavaScript（データ）:**
   - ファイル名: `js/data.js`
   - 内容をコピー＆ペースト
   - コミット

   **c. JavaScript（メイン）:**
   - ファイル名: `js/main.js`
   - 内容をコピー＆ペースト
   - コミット

   **d. HTML:**
   - ファイル名: `index.html`
   - 内容をコピー＆ペースト
   - コミット

3. **GitHub Pagesを有効化**（上記手順2を参照）

## 🔧 トラブルシューティング

### CSSが適用されない
- **解決策1:** ブラウザキャッシュをクリア（Ctrl+Shift+R / Cmd+Shift+R）
- **解決策2:** GitHub Actionsの完了を確認
- **解決策3:** ファイルパスが正しいか確認（`./css/style.css`）

### 地図が表示されない
- Leafletライブラリの読み込みを確認
- JavaScriptエラーがないか開発者ツールで確認

### 経路が取得できない
- OSRM APIが利用可能か確認
- 自宅住所が正しくジオコーディングされているか確認

### 駅候補が表示されない
- `STATIONS_DATA`配列が正しく読み込まれているか確認
- コンソールでエラーがないか確認
